# قائمة تنقل متجاوبة | Responsive Navigation Menu

## 📌 نبذة عن المشروع

مشروع يهدف إلى إنشاء قائمة تنقل متجاوبة باستخدام HTML وCSS وJavaScript، تعمل على أجهزة الكمبيوتر والهواتف المحمولة، مع توفير تجربة استخدام سهلة وإمكانية الوصول لمستخدمي التقنيات المساعدة.

يتضمن المشروع قائمة تنقل تتغير طريقة عرضها حسب حجم الشاشة، بالإضافة إلى تمييز رابط القسم الحالي أثناء التمرير داخل الصفحة.

## 🎯 أهداف المشروع

- إنشاء قائمة تنقل متجاوبة مع مختلف أحجام الشاشات.
- تطبيق مبادئ تنظيم HTML وتنسيق CSS.
- استخدام JavaScript للتحكم في فتح القائمة وإغلاقها.
- تحسين إمكانية الوصول باستخدام خصائص ARIA.
- استخدام `IntersectionObserver` لمراقبة الأقسام وتحديث رابط التنقل النشط.
- تطبيق مبدأ فصل الهيكل عن التنسيق والسلوك.

## 🛠️ التقنيات المستخدمة

- **HTML5:** بناء هيكل الصفحة وإنشاء روابط التنقل والأقسام.
- **CSS3:** تنسيق الصفحة، وتصميم القائمة، وتطبيق التصميم المتجاوب باستخدام Media Queries وFlexbox.
- **JavaScript:** التحكم في القائمة والتعامل مع أحداث المستخدم ومراقبة الأقسام أثناء التمرير.

## ✨ مميزات المشروع

### 1. تصميم متجاوب

- على الشاشات الكبيرة، تظهر روابط التنقل بجانب اسم الموقع.
- على الشاشات التي يبلغ عرضها 720 بكسل أو أقل، يظهر زر القائمة وتتحول الروابط إلى قائمة منسدلة.

### 2. فتح القائمة وإغلاقها

يمكن للمستخدم فتح القائمة وإغلاقها من خلال زر القائمة، مع تحديث حالة العنصر باستخدام `aria-expanded` وإضافة أو إزالة الصنف `is-open`.

### 3. إغلاق القائمة بطرق متعددة

تُغلق القائمة عند:
- الضغط على أحد روابط التنقل.
- الضغط على مفتاح `Escape`.
- الضغط خارج القائمة وزر فتحها.

### 4. تمييز القسم الحالي

يستخدم المشروع `IntersectionObserver` لمراقبة أقسام الصفحة، ثم يحدّث خاصية `aria-current` للرابط المرتبط بالقسم الذي تتم مراقبته، مما يساعد على تمييزه بصريًا باستخدام CSS.

### 5. تحسين إمكانية الوصول

يتضمن المشروع خصائص ARIA، مثل:
- `aria-label`: توفير اسم وصفي للزر أو منطقة التنقل.
- `aria-expanded`: توضيح حالة القائمة، مفتوحة أو مغلقة.
- `aria-controls`: ربط زر القائمة بعنصر التنقل الذي يتحكم فيه.
- `aria-current`: تحديد رابط القسم الحالي.

كما يعيد التركيز إلى زر القائمة عند إغلاقها باستخدام مفتاح `Escape`.

1. قم بتنزيل المشروع أو استنساخ المستودع باستخدام Git.
2. افتح مجلد المشروع في محرر الأكواد، مثل Visual Studio Code.

## 📚 ما تعلمته من المشروع

- استخدام محددات DOM للوصول إلى عناصر HTML.
- التعامل مع الأحداث باستخدام `addEventListener`.
- استخدام `classList.toggle()` للتحكم في أصناف CSS.
- استخدام `forEach()` للتعامل مع مجموعة من العناصر.
- التعامل مع أحداث لوحة المفاتيح والنقر خارج عنصر معين.
- فهم خصائص ARIA وأهميتها في تحسين إمكانية الوصول.
- استخدام `IntersectionObserver` لمراقبة ظهور العناصر داخل نافذة العرض.
- بناء واجهة متجاوبة باستخدام CSS Media Queries وFlexbox.
